# Try Jesus Media — Lesson 1

This ZIP contains a complete static mobile Bible study page for:

`https://tryjesusmedia.com/lesson1/`

## Folder structure

```text
lesson1/
├── index.html
└── assets/
    ├── styles.css
    └── script.js
```

## GitHub upload

1. Upload the entire `lesson1` folder to the web root of the repository that powers TryJesusMedia.com.
2. Confirm the host serves `lesson1/index.html` at `/lesson1/`.
3. Commit and deploy.

## Before publishing

- Replace the temporary text-based `TJ` brand mark with the official Try Jesus Media logo if desired.
- Review the Scripture summaries and replace them with the exact translation text you are licensed or permitted to publish.
- Confirm `/lesson2/` is the correct destination for the final CTA.
- Confirm `https://zoombiblestudy.com` is the correct live-discussion destination.
- Add your preferred historical-source links inside the evidence drawers.

## Features included

- Eight-screen mobile-first lesson flow
- ClickFunnels-inspired premium visual hierarchy
- Sticky progress indicator
- Interactive Daniel 2 statue
- Expandable Scripture cards
- Historical evidence drawers
- Browser-based audio narration
- Private reflection fields saved locally
- Automatic lesson progress saving
- Keyboard navigation with left/right arrow keys
- Responsive layout and accessibility focus states

No framework, build step, or package installation is required.
