CLOUDFLARE ENVIRONMENT VARIABLES REQUIRED FOR ANSWERS
------------------------------------------------------
In your Cloudflare Pages project, add these server-side variables/secrets:

OPENAI_API_KEY = your OpenAI API key
OPENAI_VECTOR_STORE_ID = the vector store created from the Pastor Kal knowledge files
OPENAI_MODEL = gpt-5.6   (optional; defaults to gpt-5.6)

Without OPENAI_API_KEY, the Pastor Kal button/window will still appear, but it will tell you that the API key has not been connected yet when you ask a question.

KNOWLEDGE-BASE SETUP
--------------------
On a computer with Node.js installed, from the repository root:

1. npm install
2. Set OPENAI_API_KEY in your shell/environment.
3. npm run sync:guides
4. npm run kb:upload
5. Copy the printed OPENAI_VECTOR_STORE_ID into Cloudflare Pages environment variables.
6. Redeploy the Cloudflare Pages project.
