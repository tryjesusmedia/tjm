# Website integration snippets

## Welcome page
Add `welcome-page-install-card.html` to `tryjesusmedia.com/welcome` after the visitor has received the discussion/access information. This is the prominent install invitation.

## Main landing page
Add `landing-page-soft-app-link.html` near the footer only. It is intentionally subtle so it does not compete with the landing page's primary conversion goal.

Both snippets assume the app is deployed at `https://tryjesusmedia.com/app/`. Change `/app/` in the links if you deploy it elsewhere.
